# Geochemistry-GGchem-extraction-program
---Version française ci-dessous---

The geochemistry GGchem extraction code is used to extract and process the data produced by the GGchem modelling code. The GGchem code is used to model condensation from a defined gas cloud over a range of temperatures and pressures. The GGchem code is described in the paper Woitke et al, 2018 and is available through the link https://github.com/pw31/GGchem. The GGchem code produces an output file (‘Static_Conc.dat’). Our GGchem data processing code opens this file and extracts the data to convert the compositions of the different phases in the gas into partial pressures and for the condensates into mole fractions. This code produces matrices with the different composition for the gases, condensates or phases with a specific atom (O, Si, Al, and Ca).

This code will also estimate the condensation start temperature, the temperature at 50% condensation, and the temperature at the end of the condensation for each of the condensates produced by the GGchem model.

This code will also calculate the fO and fSi, i.e. the fraction of oxygen and silicon remaining in the gases during condensation. The fSi is then used to calculate the δ30Si. To calculate the δ30Si and its evolution during condensation, the code will estimate the α and Δ30Sigas-condensate values for the kinetic isotope fractionation produced during condensation for each temperature observed by the GGchem code simulation. And, the δ30Si of the gas and condensate is calculated for each temperature.

Finally, the code saves the various lists in a series of .csv files. In particular, the recorded data saved are the partial pressures of the gases, the evolution of the amount of condensates, the fO and fSi data, and the δ30Si. A series of graphs can also be produced by the code representing the evolution of the partial pressure for the different gases bearing Si or O and the total partial pressure as a function of temperature, or the monitoring of condensate formation as a function of temperature. The code can also plot the evolution the different fractions of Si- or O-rich gas phases, such as fSiO, fSiO2, fSiatom, fO2, fOH, fH2O, and the values of fSitot and fOtot as a function of temperature. The values of Δ30Sigas-condensate are represented in the fSi graph. The code can also represent the δ30Si values of the condensates as a function of temperature. Some figures are designed to be saved automatically as .png files.

This code is a work in progress and will evolve over time.

---Version française---

Le code geochemistry GGchem extraction permet d’extraire et de traiter les données produites par le code de modélisation GGchem. Le code GGchem permet de simuler la condensation à partir d’un gaz défini sur une gamme de température et sur une gamme de pression. Le code GGchem est décrit dans l’article Woitke et al., 2018 et disponible à travers le lien https://github.com/pw31/GGchem. Le code GGchem produit un fichier de sortie (« Static_Conc.dat »). Notre code de traitement des données GGchem ouvre ce fichier et en extrait les données pour convertir les compositions des différentes phases dans le gaz en pressions partielles et des condensats en fractions molaires et produire des matrices avec les compositions des différents gaz, condensats ou des phases ayant un atome spécifique (O, Si, Al, et Ca).

Ce code va aussi estimer la température de début de condensation, la température à 50% de la condensation, et la température de fin de condensation pour chacun des condensats produits pour le modèle GGchem.

Ce code va aussi calculer le fO et fSi, i.e. la fraction d’oxygène et de silicium restant dans les gaz au cours de la condensation. Le fSi est utilisé par la suite pour calculer le δ30Si. Pour calculer le δ30Si et son évolution durant la condensation, le code va estimer les valeurs des α et des Δ30Sigaz-condensat pour le fractionnement isotopique cinétique produit durant la condensation pour chaque température observée par la simulation GGchem. Enfin, les δ30Si du gaz et des condensats est calculé pour chaque température.

Enfin, ce code enregistre les différentes listes dans une série de fichiers .csv. Les données enregistrées sont les pressions partielles des gaz, les l’évolution de la quantité de condensats, les données de fO et fSi, et de δ30Si. Une série de graphiques peut aussi être produite par le code représentant l’évolution de la pression partielle pour les différentes phases ayant des atomes de Si ou O et la pression partielle totale en fonction de la température, ou le suivi de la formation des condensats en fonction de la température. Le code permet aussi de représenter l’évolution des fractions des différentes phases gazeuses riches en Si ou en O comme fSiO, fSiO2, fSiatome, fO2, fOH, fH2O, et les valeurs de fSitot et fOtot en fonction de la température. Le code permet aussi représenter les valeurs de Δ30Sigaz-condensat dans le graphique montrant les fSi. Le code peut aussi représenter les valeurs de δ30Si des condensats en fonction de la température. Certaines figures sont prévues pour être enregistrées automatiquement en tant que fichiers .png.

Ce code est un travail en cours et évoluera avec le temps.
